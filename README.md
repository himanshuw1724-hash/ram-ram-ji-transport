# RAM RAM JI TRANSPORT - Fleet & Payment Portal

Automated 24/7 School Bus Fleet Management and Parent Fee Payment Portal.

## Features
- **Admin Dashboard**: Student management, bus routes, school directories, cash payments, stop fee, financial year controls.
- **Parent Payment Portal**: Instant bus selection, student fee cards, UPI QR scanner, bank transfer details, verified receipt download.
- **Security**: 256-bit SSL encryption, token authorization, password protection.

## Deployment on Render
1. Connect this repository to [Render.com](https://render.com).
2. Choose **Web Service**.
3. Render will auto-detect Node.js and deploy with `npm start`.
